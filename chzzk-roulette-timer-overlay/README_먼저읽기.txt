치지직 후원 룰렛 타이머 - 먼저 읽어주세요

1. 처음 설치
   setup.bat을 한 번 실행하세요.

2. 실행
   start.bat을 실행하세요.
   검은 창이 열리면 프로그램이 켜진 상태입니다.
   OBS를 쓰는 동안 검은 창을 닫지 마세요.

3. 관리자 페이지
   http://localhost:3000/admin

4. OBS 오버레이 주소
   http://localhost:3000/overlay

5. OBS 브라우저 소스 권장 크기
   너비 820
   높이 80

6. 테스트 후원
   관리자 페이지에서 후원 금액을 입력하고 실행 버튼을 누르면 됩니다.

7. 확률표 수정
   관리자 페이지의 확률표 편집에서 수정하고 저장 버튼을 누르세요.

8. config.json이 망가졌을 때
   config.example.json을 복사해서 config.json으로 이름을 바꾸면 기본 설정으로 복구됩니다.

9. 타이머와 최근 로그를 초기화하고 싶을 때
   state.example.json을 복사해서 state.json으로 이름을 바꾸면 됩니다.

10. 치지직 실제 후원 연동
   현재 버전에서는 아직 구현 전입니다.
   지금은 테스트 후원 기능으로 동작을 확인하세요.
