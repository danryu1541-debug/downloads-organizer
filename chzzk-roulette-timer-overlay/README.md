# 치지직 후원 룰렛 타이머

치지직 후원 금액에 따라 룰렛을 돌리고, 결과에 맞춰 **멧돼지 시간**과 **돼지 시간**을 따로 조절하는 OBS 오버레이 프로그램입니다.

> 현재 버전은 **테스트 후원 모드** 중심입니다.  
> 치지직 실제 후원 자동 연동은 아직 구현 전이며, 추후 고급 설정으로 지원할 예정입니다.

## 바로가기

프로그램을 실행한 뒤 아래 주소를 사용합니다.

```text
관리자 페이지
http://localhost:3000/admin

OBS 오버레이 주소
http://localhost:3000/overlay
```

OBS 브라우저 소스 권장 크기:

```text
너비 820
높이 80
```

## 이 프로그램으로 할 수 있는 것

- 멧돼지 타이머와 돼지 타이머를 따로 표시합니다.
- 후원 금액별로 다른 룰렛 확률표를 사용할 수 있습니다.
- `3,900원`, `4,000원`은 1회 룰렛으로 설정되어 있습니다.
- `39,000원`, `40,000원`은 10회 연차 룰렛으로 설정되어 있습니다.
- 룰렛 결과가 여러 번 나오면 순서대로 모두 타이머에 반영합니다.
- 타이머는 0초 아래로 내려가지 않습니다.
- OBS 오버레이는 검은 배경과 흰 글자의 미니멀한 가로형 UI입니다.
- 관리자 페이지에서 타이머, 테스트 후원, 확률표, 오버레이 모양을 관리할 수 있습니다.

## 설치 전 준비물

### 필수

- Windows PC
- OBS Studio
- Node.js LTS

Node.js는 아래 주소에서 LTS 버전을 설치하면 됩니다.

```text
https://nodejs.org/
```

### 아직 필요하지 않은 것

치지직 실제 후원 자동 연동은 아직 구현 전입니다.  
현재 테스트 모드만 사용할 때는 치지직 개발자센터 앱 등록이나 토큰 입력이 필요하지 않습니다.

## 처음 설치하는 방법

1. 받은 ZIP 파일을 원하는 폴더에 압축 해제합니다.
2. 폴더 안의 `setup.bat`을 실행합니다.
3. 설치가 끝나면 창을 닫아도 됩니다.

`setup.bat`은 처음 한 번만 실행하면 됩니다.

## 실행 방법

1. 폴더 안의 `start.bat`을 실행합니다.
2. 검은 창이 열리면 프로그램이 실행된 상태입니다.
3. OBS를 쓰는 동안 이 검은 창을 닫지 마세요.

검은 창을 닫으면 관리자 페이지와 OBS 오버레이도 같이 꺼집니다.

실행 후 브라우저에서 관리자 페이지를 엽니다.

```text
http://localhost:3000/admin
```

## 관리자 페이지 사용법

관리자 페이지 주소:

```text
http://localhost:3000/admin
```

관리자 페이지에서 할 수 있는 일:

- 멧돼지 타이머 시작, 정지, 초기화
- 돼지 타이머 시작, 정지, 초기화
- 각 타이머 시간 추가, 감소
- 테스트 후원 실행
- 최근 룰렛 결과 확인 및 초기화
- 금액별 룰렛 확률표 수정
- OBS 오버레이 가로 길이, 세로 높이, 투명도, 글자 크기 조절

## OBS 오버레이 등록 방법

1. OBS를 실행합니다.
2. 원하는 장면에서 `소스`의 `+` 버튼을 누릅니다.
3. `브라우저`를 선택합니다.
4. URL에 아래 주소를 입력합니다.

```text
http://localhost:3000/overlay
```

5. 너비와 높이를 입력합니다.

```text
너비: 820
높이: 80
```

6. 방송 화면 왼쪽 상단에 배치합니다.

오버레이 크기나 글자가 마음에 들지 않으면 관리자 페이지의 `오버레이 설정`에서 조절한 뒤 OBS 브라우저 소스를 새로고침하면 됩니다.

## 테스트 후원 사용법

현재는 실제 치지직 후원 자동 연동 전 단계이므로, 관리자 페이지에서 테스트 후원을 실행해 동작을 확인합니다.

1. 관리자 페이지를 엽니다.
2. `테스트 후원 실행` 영역에 금액을 입력합니다.
3. `실행` 버튼을 누릅니다.

기본 금액:

- `3900`: 증가 룰렛 1회
- `4000`: 감소 룰렛 1회
- `39000`: 증가 룰렛 10회
- `40000`: 감소 룰렛 10회

## 확률표 수정 방법

관리자 페이지의 `확률표 편집`에서 수정합니다.

각 항목의 의미:

- `화면 표시 문구`: 룰렛 결과와 최근 로그에 보이는 문구입니다.
- `확률 비중`: 숫자가 클수록 더 잘 뽑힙니다. 50과 50이면 반반입니다.
- `대상`: 멧돼지 타이머 또는 돼지 타이머입니다.
- `동작`: 증가 또는 감소입니다.
- `적용 시간`: 타이머에 반영할 시간입니다. 분 단위로 입력합니다.

수정 후에는 반드시 `저장` 버튼을 누르세요.

## 설정 파일 설명

중요한 파일은 아래와 같습니다.

```text
config.json
룰렛 확률표와 오버레이 설정이 저장됩니다.

state.json
현재 타이머 시간과 최근 룰렛 결과가 저장됩니다.

config.example.json
config.json이 망가졌을 때 복구할 수 있는 기본 설정 백업입니다.

state.example.json
state.json을 초기화할 때 사용할 수 있는 빈 상태 백업입니다.
```

## config.json 복구 방법

확률표를 잘못 수정해서 프로그램이 이상하게 동작하면 아래 순서대로 복구합니다.

1. `start.bat` 검은 창을 닫습니다.
2. `config.json` 파일 이름을 `config.broken.json`으로 바꿉니다.
3. `config.example.json`을 복사합니다.
4. 복사한 파일 이름을 `config.json`으로 바꿉니다.
5. `start.bat`을 다시 실행합니다.

타이머와 최근 로그까지 완전히 초기화하고 싶으면 `state.example.json`을 복사해서 `state.json`으로 바꾸면 됩니다.

## 치지직 실제 연동

아직 구현 전입니다.

현재 버전:

- 관리자 페이지에서 테스트 후원 실행
- 룰렛 계산
- OBS 오버레이 표시

추후 지원 예정:

- 치지직 개발자센터 앱 정보 입력
- 치지직 로그인 또는 토큰 설정
- DONATION 이벤트 자동 수신
- 실제 후원 금액에 따라 룰렛 자동 실행

치지직 실제 연동 관련 값은 나중에 `.env` 파일에 입력하는 방식으로 사용할 예정입니다.

## 자주 발생하는 문제

### 관리자 페이지나 오버레이가 열리지 않습니다

`start.bat`이 실행 중인지 확인하세요.  
검은 창을 닫으면 프로그램도 꺼집니다.

### ERR_CONNECTION_REFUSED가 나옵니다

서버가 꺼진 상태입니다. `start.bat`을 다시 실행하세요.

### 3000번 포트를 이미 사용 중이라고 나옵니다

`.env` 파일에서 포트를 바꿀 수 있습니다.

```text
PORT=3001
```

포트를 바꾸면 주소도 같이 바뀝니다.

```text
http://localhost:3001/admin
http://localhost:3001/overlay
```

### OBS에서 화면이 예전 모습으로 보입니다

OBS 브라우저 소스를 새로고침하거나, 소스를 껐다가 다시 켜보세요.  
브라우저에서 확인할 때는 `Ctrl+F5`로 강력 새로고침하세요.

### 한글이 깨져 보입니다

최신 버전에서는 UTF-8로 정리되어 있습니다.  
브라우저 또는 OBS 캐시가 남아 있을 수 있으니 새로고침하세요.

### 특정 금액 테스트 후원이 반응하지 않습니다

관리자 페이지의 `확률표 편집`에 해당 금액이 등록되어 있는지 확인하세요.

### 타이머 시간이 이상합니다

관리자 페이지에서 타이머를 초기화하세요.  
그래도 이상하면 `state.example.json`을 `state.json`으로 복사해 초기화할 수 있습니다.

## 배포할 때 포함하면 좋은 파일

다른 사람에게 전달할 때는 아래 파일과 폴더를 포함하면 됩니다.

```text
public/
src/
config.example.json
config.json
state.example.json
package.json
package-lock.json
server.js
setup.bat
start.bat
README.md
README_먼저읽기.txt
.env.example
```

`node_modules` 폴더는 없어도 됩니다. 받은 사람이 `setup.bat`을 실행하면 다시 설치됩니다.
